# 潮灯记 · 迷你 JRPG

一个用 **纯 HTML5 Canvas + JavaScript** 写成的回合制 JRPG。v5.0 换上全新剧情《潮灯记》：潮灯镇的记忆之灯熄灭，你要去雾语林讨回灯芯——而井底还有更深的真相。系统仍是 `S` 状态对象、单向依赖、技能克制与任务日志，零依赖、无构建、完全离线。

## 🚀 如何运行（重要）

由于使用了 ES Modules，浏览器会**拦截 file:// 协议下的模块跨域加载**，不能再直接双击 `index.html`。请用一键启动脚本（自动起本地服务器并打开浏览器）：

- **macOS**：在 Finder 中**双击 `start.command`**（会自动打开终端 + 浏览器）
- **任意平台（终端）**：
  ```bash
  cd ~/Downloads/my-jrpg
  ./start.sh
  ```
- **手动方式**：`python3 -m http.server --bind 127.0.0.1 8000`，然后浏览器打开 `http://localhost:8000/`（v21.90 起一键脚本与手动命令均默认仅绑定本机 `127.0.0.1`，不向局域网暴露；如需局域网联机试玩，把 `--bind 127.0.0.1` 去掉即可）

> 服务器只需要静态文件服务即可（Nginx / `python3 -m http.server` / VS Code 的 Live Server 等都行）。

**设计要点**

- **单向依赖**：`data → rules → systems（world/battle/encounter/enemyAI/shop）→ view`。系统不 import 绘制，经 `bind` 晚绑定（仅 view 注册、每键单点）；system 间反向调用经 `hooks` 晚绑定。
- **共享状态**：各模块 `import { S }`，改 `S.scene` / `S.G`；当前地图唯一真相是 `G.map`，读取走 `curMap()`。
- **view 只读**：绘制层不改游戏状态——游戏时钟由 main.js 的 tick 推进，行走插值态由 world.walking() 惰性清除。
- **零依赖零构建**：浏览器原生 ESM。验证：`npm test`。

## 🧱 技术说明

- 图块 / 角色优先用 `assets/puny/` 的 Puny CC0 像素图（16×16 图块放大到 32px）；加载失败时退回 Canvas 程序化绘制。
- 音乐 / 音效全部用 Web Audio API 实时合成（步进音序器）。
- 数据持久化用 `localStorage`（`jrpg_save1/2/3`）。
- 现代 Chrome/Edge/Firefox/Safari 均可运行。
- 每次改动后执行 `npm run check` + `npm test`。
