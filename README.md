# 潮灯记 · 迷你 JRPG

一个用 **纯 HTML5 Canvas + JavaScript** 写成的回合制 JRPG。v5.0 换上全新剧情《潮灯记》：潮灯镇的记忆之灯熄灭，你要去雾语林讨回灯芯——而井底还有更深的真相。系统仍是 `S` 状态对象、单向依赖、技能克制与任务日志，零依赖、无构建、完全离线。

## 🚀 如何运行（重要）

由于使用了 ES Modules，浏览器会**拦截 file:// 协议下的模块跨域加载**，不能再直接双击 `index.html`。请用一键启动脚本（自动起本地服务器并打开浏览器）：

- **macOS**：在 Finder 中**双击 `start.command`**（会自动打开终端 + 浏览器）
- **任意平台（终端）**：
  ```bash
  cd ~/Downloads/my-jrpg
  ./start.sh
  ```
- **手动方式**：`python3 -m http.server 8000`，然后浏览器打开 `http://localhost:8000/`

> 服务器只需要静态文件服务即可（Nginx / `python3 -m http.server` / VS Code 的 Live Server 等都行）。

| 标题 `1/2/3` | 选择存档槽，`L` 读档 |

**战斗**：`1` 攻击 · `2` 技能（再按数字选，右侧实时标注 MP 消耗与期望伤害）· `3` 药水（指令栏实时显示余量与恢复量预览——`[3]恢复：🍖+NHP 🧪+NHP/+NMP`，满状态不浪费）· `4` 逃跑（普通怪约 60% 成功，指令栏实时标注成功率；Boss 战被气场压制，指令置灰 ⛔ 且不耗回合）· `5` 防御（本回合减伤一半并回 2 MP，被命中 50% 几率趁隙反击）· `6` 蓄力（下一次攻击或技能威力 ×1.5，与暴击可叠加）。技能已分化：火焰斩灼烧（敌方角标 `🔥 灼烧 N · 每回合 -X血`，与结算同源的每回合扣血数值）、冰霜击概率冻结（冻结时敌方角标常驻 `❄️ 冻结`，下回合无法行动）、雷鸣穿防、陨石碎甲并克真身、治愈术同时解毒（我方中毒角标 `☠️ 中毒 N 回合 · 每回合 -X血` 实时显示每回合扣血，一眼决定净化/速战）。图鉴显示弱点。危险区踩踏积攒遭遇槽（小地图下红条 + 百分比读数，≥70% 闪烁鸣警 ⚠️ 危险逼近），满 100 必遇敌；喷泉/道路会下降。终焉之神祸乱形态会封印治愈（指令 ⛔）。战斗画面左上角常驻 `⚔️ 回合 N` 计数，实时显示敌我 攻/防 对比与战利品预览（精英追加标注 `🍄 必掉蘑菇`，终焉之神另注 `战胜另+300金`）；玩家拟行动回合底部常驻**敌方攻击预判**（`敌方攻击预判：-N血（防御后-N血）`，防御中则直接显示 `格挡中 · 本回合只受 -N血`，致命时橙色 ⚠️ 标红——致命判定随防御态切换，与结算公式逐字同源），一眼判断该攻击还是防御/用药；**Boss/试炼战同样常驻逐招受击预判**（`敌方攻击预判：普攻 -N血 · 重击 -M血（防御后-N/M血）`，防御中显示 `格挡中 · 普攻 -N血 · 重击 -M血`，重击倍率与结算同源——真身 2.3 / 平时 1.9，任一招可能致命即橙色 ⚠️ 警示——Boss 战不再靠猜该防哪刀）；技能菜单右侧逐项标注 MP 消耗（蓝=够用 · 红=不足 · 灰=封印）；**敌我双方血条右侧均常驻精确数值**（敌方如 `130/260`、我方如 `123/180`，与血条同色、击杀瞬间钳制为 0），Boss/试炼战同样可一眼看清我方剩余血量蓝量；Boss 血条中线的**二段变身线**标注精确触发阈值（如 `二段变身线 · HP<130`，与变身判定公式同源、困难模式实时联动）；会使用多招的强敌（Boss/精英）在战斗画面右上角常驻**敌方招数一览**（如 `敌方招数：普攻 / 重击 / 回血·血<40%时`；石甲带 `血<50%时·至多3层`，变身后追加 `真身后强`，治愈被封印时标注 `⛔封印`——直接读取敌方行动表同源数据，纯显示、不剧透出招权重），提前看清它可能怎么打；**石心魔像/洞窟领主凝甲时，`[1]攻击` 与技能 `≈N伤` 预览自动计入石甲减伤**（与命中结算的 `×0.6` 逐字同源，盾一消弹回原值——不再虚报伤害）。

## 🗺️ 三张地图与主线目标

1. **潮灯镇** — 起点。商店（买药/装备/卖蘑菇）、旅馆（回血）、酿造锅（蘑菇→高级灵药）、灯长支线（用荧光蘑菇唤醒井泉）、喷泉回血。
2. **雾语林** — 强魔物 + 精英「石心魔像」（Lv3 起才有机会撞见）；深处的 **Boss 幽冥魔王**（二阶段「真身」，实为吞走灯芯的旧灯卫）；右下裂洞通往矿脉；营地泉水旁的 **雾径猎手** 指点泉水与毒蛇/石心魔像。
3. **星井矿脉** — 迷宫，更强的魔物；入口处有井巫点破「魔王只是锁，水晶里才是灯自己」；矿车区旁的 **星砂车夫** 说明星砂矿车；洞窟领主（迷你Boss）；击败魔王+洞窟领主后，中央 **终焉水晶** 醒来 → 隐藏真Boss「终焉之神」（初灯的意志）→ 真·结局。击败洞窟领主后，矿车区旁的 **星砂宝箱**（2×2）当场显形。

## ✨ 系统清单

- **角色创建**：3 个姓名（余烬 / 灯见 / 潮）× 普通/困难难度（困难：敌×1.35血/×1.15攻/×1.12防）
- **职业成长**：经验升级（状态界面 `I` 经验行常驻 `经验 X/Y · 距升级还差 N 经验` 精确读数）、等级解锁技能（火焰斩灼烧→冰霜击冻结→治愈术解毒→雷鸣穿防→陨石碎甲），状态界面（`I`）显示技能效果说明与下一技能经验预估；**`J` 任务日志**主线/支线分列（可接·进行中·可交付·已完成），横幅同源并**常驻任务目的地地点提示**（如支线 `找回魔法蘑菇 0/3 株（雾语林宝箱 → 回镇找灯长）`、主线 `深入星井矿脉（星井矿脉深处）`——与日志 `地点` 同源，文案已含地点则不重复叠加）
- **装备系统**：4 档武器 + 传说「圣光之剑」（Boss掉落）；4 档防具
- **经济循环**：金币 / 药水 / 高级灵药 / 魔法蘑菇（宝箱·精英·掉落 → 酿造 → 售卖；HUD 常驻 🍄 背包计数）
- **战斗**：回合制、技能粒子特效、飘字、Boss 二阶段、战利品掉落、精英/双Boss、威胁预警、技能期望伤害预览
- **图鉴 & 成就**：击败记录 + 报酬参考（击败可得经验/金币）+ **已讨伐行魔物强度数值**（`HP X 攻 Y 防 Z` 随玩家等级实时参考，与遇敌属性同源、未讨伐不剧透）+ 已讨伐行特殊掉落/特性标注（毒蛇 ☠️ 会施毒、精英必掉魔法蘑菇、幽冥魔王必掉圣光之剑、洞窟领主清除祭坛、终焉之神额外+300金）+ 出没地点指引 + 未收集灰色占位（一眼看清还差哪几种）+ ↑↓ 滚动，**15 项成就**（`C` 键成就一览：✔已解锁/✘未解锁 + 计数成就实时进度如 7/10 只、123/500 金、图鉴 3/11 种）
- **BGM / 音效**：Web Audio 主题乐 + 村庄/森林/洞窟/战斗分场景配乐（星井矿脉有专属低沉洞穴曲目）+ 十余种音效
- **视觉**：Shade「Puny」CC0 像素图块与角色（16×16 图块 2× 到 32px 格；贴图缺失时退回程序化绘制）、昼夜循环（**HUD 地图名旁常驻昼夜标签** `☀️ 白天 / 🌆 黄昏 / 🌙 夜晚 / 🌅 黎明`，每 90 秒一档、与画面着色同源同步）、洞窟雨幕、标题星光粒子、小地图（含**危险区红色标注**：混合地形中真正会遇敌的草丛一眼可见，森林/洞窟全域危险则不叠涂）；主角**圣剑/龙鳞甲换红衣战士**，怪物**按物种差异化造型**（像素图集 + 部分程序化剪影），星井矿脉为**地下岩地+荧光晶尘**主题
- **系统**：三存档槽（localStorage）、**标题页存档进度预览**（选槽即见该档姓名/等级/金币/地图/主线进度）、任务目标动态指引、**状态界面冒险进度四徽记**（`I` 键一眼看清灯芯/星井/初灯/试炼场四格进度，达成亮绿 ✓·未达成灰 ✗，与成就/摘要同源）、快速旅行（含各目的地推荐等级/特色提示、当前所在地 📍 标注）、**强敌祭坛等级标签与试炼碑状态标签**（未讨伐祭坛常驻 `⚠ Lv.X`：魔王8/洞窟领主7/终焉之神12，击败自动熄灭；试炼碑 未解锁 / ⚔️ 可挑战）、四页操作帮助（操作 / 地图指南 / 魔物状态 / 试炼进阶）、**冒险时长**（状态界面 I 与尾声战绩页显示 `⏱️` 实时计时，随存档持久化）、**面向可交互对象上下文提示**（面向 NPC 显示 `⏎ 对话·名字`——灯长/镇民/巡灯人/井巫/雾径猎手/星砂车夫一目了然，面向 商店/旅馆/酿造锅 显示 `⏎ 商店/旅馆/酿造`，面向 喷泉 显示 `踩上回血 · HP+N MP+N`（喷泉 HP/MP 完全恢复，提示与恢复逻辑逐字同源；满状态如实显示 `踩上回血 · 状态已满`），面向 宝箱/强敌祭坛/试炼碑 显示 `踩上开启/开战/触发/挑战`，面向**传送门/出口**则直接标注目的地 `踩上通行 → 雾语林` 等——与真实传送同源）、**可交互任务顶标**（灯长/星砂车夫正有「可接委托 / 可交任务」时，世界画面头顶脉冲 `❕ 可接委托 / 可交任务`，与任务日志同源，一眼知道该找谁说话；纯闲聊 NPC 不显示），已讨伐/已开自动熄灭、**战败复盘**（阵亡画面先显示 `败于 {敌人}` 与当前 等级/金币/累计讨伐/游玩时长，再按死因给出情境建议——Boss 战提示补给练级后按 B 重整旗鼓、普通怪提示回村补给并看图鉴）、**HUD 常驻存档槽指示**（`💾槽N` 与当前槽位同源，按 P 存档前一眼看清写进哪槽）

## 🧱 项目结构（v5.0）

```
my-jrpg/
├── index.html              # 页面壳：DOM/样式 + <script type="module" src="js/main.js">
├── assets/puny/            # Shade Puny CC0 像素图集（缺图时自动退回程序化）
├── js/
│   ├── main.js             # 入口：goto + 场景按键表
│   ├── state.js            # 导出共享对象 S（禁止 globalThis）
│   ├── data.js             # 纯数据：地图/技能/敌人行为表/任务定义
│   ├── rules.js            # 无副作用：伤害、弱点、成长、成就判定
│   ├── bind.js             # 系统↔绘制 晚绑定（拆环）
│   ├── scene.js            # goto(scene)
│   ├── audio.js            # Web Audio
│   ├── quests.js           # 任务状态机（兼容旧 G.quest）
│   ├── hero.js             # 药水/领悟/成就应用
│   ├── shop.js             # 商店/旅馆购买（不在绘制层）
│   ├── core.js             # 存档/对话/开局
│   ├── world.js            # 地图/移动/遭遇槽/胜利改地图
│   ├── battle.js           # 回合队列/技能/结算（返回结果）
│   ├── ui.js               # 视图桶文件（re-export view/）
│   └── view/               # canvas / atlas / tiles / sprites / hud / drawWorld / drawBattle / menus
├── tests/smoke.mjs         # 仓库内 ESM 冒烟
├── improve-plan.md         # 架构与系统改进计划
├── start.command / start.sh
├── package.json            # npm test / npm run check
└── preview.png
```

**设计要点**

- **单向依赖**：`data → rules → systems（world/battle/shop）→ view`。系统不 import 绘制，经 `bind` 晚绑定。
- **共享状态**：各模块 `import { S }`，改 `S.scene` / `S.G`。
- **零依赖零构建**：浏览器原生 ESM。验证：`npm test`。

## 🧱 技术说明

- 图块 / 角色优先用 `assets/puny/` 的 Puny CC0 像素图（16×16 图块放大到 32px）；加载失败时退回 Canvas 程序化绘制。
- 音乐 / 音效全部用 Web Audio API 实时合成（步进音序器）。
- 数据持久化用 `localStorage`（`jrpg_save1/2/3`）。
- 现代 Chrome/Edge/Firefox/Safari 均可运行。
- 每次改动后执行 `npm run check` + `npm test`。
