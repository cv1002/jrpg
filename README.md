# 潮灯记 · 迷你 JRPG

一个用 **纯 HTML5 Canvas + JavaScript** 写成的回合制 JRPG。v5.0 换上全新剧情《潮灯记》：潮灯镇的记忆之灯熄灭，你要去雾语林讨回灯芯——而井底还有更深的真相。系统仍是 `S` 状态对象、单向依赖、技能克制与任务日志，零依赖、无构建、完全离线。

## 🚀 如何运行（重要）

由于使用了 ES Modules，浏览器会**拦截 file:// 协议下的模块跨域加载**，不能再直接双击 `index.html`。请用一键启动脚本（自动起本地服务器并打开浏览器）：

- **macOS**：在 Finder 中**双击 `start.command`**（会自动打开终端 + 浏览器）
- **任意平台（终端）**：
  ```bash
  cd ~/Downloads/my-jrpg
  ./start.sh
  ```
- **手动方式**：`python3 -m http.server 8000`，然后浏览器打开 `http://localhost:8000/`

> 服务器只需要静态文件服务即可（Nginx / `python3 -m http.server` / VS Code 的 Live Server 等都行）。

## 🗺️ 四张地图与主线目标

1. **潮灯镇** — 起点。广场大灯地标居中，商店（买药/装备/卖蘑菇）、旅馆（回血）、酿造锅（蘑菇→高级灵药）环广场，井在广场北；灯长支线（用荧光蘑菇续灯油）；民宅区在西北，东门出镇。
2. **雾语林** — 蛇形主路 + 北环路（蘑菇宝箱，草丛密集）+ 中段营地（泉水安全岛）；精英「石心魔像」（Lv3 起才有机会撞见）与新住客「雾灵」（Lv2 起）；深处的 **Boss 幽冥魔王**（二阶段「真身」，实为吞走灯芯的旧灯卫）；祭坛南侧裂洞通往矿脉；营地的 **雾径猎手** 指点泉水与魔物。
3. **星井矿脉** — 轨道引导线贯穿的迷宫，更强的魔物；入口处有井巫**按进度分段点破**真相（不再开局剧透）；矿车区旁的 **星砂车夫** 说明星砂矿车；洞窟领主（迷你Boss）；双徽记集齐后，中央 **终焉水晶** 化为门 → 无字回廊。击败洞窟领主后，祭坛左侧的 **星砂宝箱**（2×2）当场显形。
4. **无字回廊** — 被忘掉的名字存放处：北壁 4 块**名字石碑**（碑文与记忆碎片同源）、中段精英「残焰魔像」、东端祭坛的隐藏真Boss「终焉之神」（初灯的意志）→ 真·结局；恒暗无晨昏，漂浮字符残屑，专属低沉 BGM。

## 🧱 项目结构（v5.0）

```
my-jrpg/
├── index.html              # 页面壳：DOM/样式 + <script type="module" src="js/main.js">
├── assets/puny/            # Shade Puny CC0 像素图集（缺图时自动退回程序化）
├── js/
│   ├── main.js             # 入口：场景按键表 + 游戏时钟 tick（与渲染解耦）
│   ├── state.js            # 导出共享对象 S + curMap() 访问器（禁止 globalThis）
│   ├── data.js             # 纯数据：地图/技能/敌人行为表/任务定义/遇敌权重
│   ├── rules.js            # 无副作用：伤害、弱点、成长、掉落、成就判定
│   ├── bind.js             # 系统→绘制 晚绑定（仅 view 注册，每键单点）
│   ├── hooks.js            # system 间晚绑定（applyVictoryWorld / loadMap / openTalk）
│   ├── scene.js            # goto(scene)
│   ├── audio.js            # Web Audio
│   ├── quests.js           # 任务状态机（兼容旧 G.quest）
│   ├── hero.js             # 药水/领悟/升级结算/成就应用
│   ├── shop.js             # 商店/旅馆购买（不在绘制层）
│   ├── core.js             # 存档/对话/开局/Boss 重试
│   ├── world.js            # 地图/移动/遭遇槽/胜利改地图
│   ├── encounter.js        # 遇敌生成（成长/权重/区域修正同读 data.js）
│   ├── battle.js           # 回合队列/玩家指令/结算编排
│   ├── enemyAI.js          # 敌方行为表挑选与回合执行
│   └── view/               # canvas / atlas / tiles / sprites / hud / drawWorld / drawBattle / menus
├── tests/                  # smoke.mjs + smoke_v510_freeze.mjs（npm test 串跑）
├── improve-plan.md         # 架构与系统改进计划
├── start.command / start.sh
├── package.json            # npm test / npm run check
└── preview.png
```

**设计要点**

- **单向依赖**：`data → rules → systems（world/battle/encounter/enemyAI/shop）→ view`。系统不 import 绘制，经 `bind` 晚绑定（仅 view 注册、每键单点）；system 间反向调用经 `hooks` 晚绑定。
- **共享状态**：各模块 `import { S }`，改 `S.scene` / `S.G`；当前地图唯一真相是 `G.map`，读取走 `curMap()`。
- **view 只读**：绘制层不改游戏状态——游戏时钟由 main.js 的 tick 推进，行走插值态由 world.walking() 惰性清除。
- **零依赖零构建**：浏览器原生 ESM。验证：`npm test`。

## 🧱 技术说明

- 图块 / 角色优先用 `assets/puny/` 的 Puny CC0 像素图（16×16 图块放大到 32px）；加载失败时退回 Canvas 程序化绘制。
- 音乐 / 音效全部用 Web Audio API 实时合成（步进音序器）。
- 数据持久化用 `localStorage`（`jrpg_save1/2/3`）。
- 现代 Chrome/Edge/Firefox/Safari 均可运行。
- 每次改动后执行 `npm run check` + `npm test`。
